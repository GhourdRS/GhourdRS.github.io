Farm Run Planner

Info

RuneProfile plugin must be synced within RuneLite Plugin Hub for target account in order to use this tool.

How to set up RuneProfile

https://www.runeprofile.com/info/guide

Look up your character, tick the teleports you have, and get every patch you can use in route order with the best crop and fastest way there. Your Farming level, quests and diaries come from RuneProfile.

Ctrl + click (⌘ + click on Mac) any option's name to open its OSRS Wiki page.

Created by Ghourd

Patch timers

Ticking a step in Your route starts its timer, using this device's clock. Ticked here = ready to harvest; untick a patch to clear its timer.

Omit locations

Patches you tick here are left out of your run plan, even if a run type or your custom run includes them.

Custom run

Patches you tick here are added to your run type plan.
